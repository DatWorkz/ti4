# Twilight Imperium IV — помощник новичка

Русскоязычный интерактивный курс и шпаргалка по базовой игре Twilight Imperium IV.

## Запуск

Откройте `index.html` в браузере. Сайт полностью статический, без сборки и сервера.

## Публикация GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → / (root) → Save**.

Адрес после публикации: https://datworkz.github.io/ti4/

## Возможности

- Семишаговое обучение;
- Выбор одной из 17 базовых фракций;
- Шпаргалка по действиям и тактическому ходу;
- Чек-лист раунда;
- 8 стратегических карт;
- Быстрые ответы по правилам.

Сохранение выбора и отметок происходит локально в браузере.

Неофициальный фанатский проект, не связан с Fantasy Flight Games.
